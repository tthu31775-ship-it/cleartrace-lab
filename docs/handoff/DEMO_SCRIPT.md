# 答辩演示脚本（5 分钟，照着点）

> 开场一句话：**"这是一个把'水军摸排'做成可复核工作流的系统：803 组候选线索已经算好，新事件能自己跑算法入库，每条结果都能追到原始评论，人工复核会留痕。"**
>
> 演示前 30 秒：确认服务在跑（`npm start`），浏览器打开 `http://127.0.0.1:3000`，用 `admin@cleartrace.local` 登录。

---

## 0. 总览工作台（20 秒）

点 **总览工作台**。

说：
> "四张卡是这次的摸排盘子：账号、任务、待复核、数据集。下面是近 7 天的识别趋势，数据来自库里的真实表，不是写死的图。"

不要在这里停太久，老师会催。

---

## 1. 协同线索：803 组候选（90 秒，核心）

点 **协同线索**。

说：
> "这里是算法组算好的 803 组候选线索，覆盖 173 个事件、7,292 个账号、7,355 条评论。
> 分两列看：上面是筛选，下面是列表。排序分是**启发式加权分**，页面上标了 `heuristic / calibrated=false`——它不等于'水军概率'。"

动作：
1. 点第一行 **查看** → 抽屉打开：左边是关系图（该群组 58 个账号），右边是原文与成员表。
2. 说："每条评论都能点出 UID、时间、点赞、节点定位；这是**可追溯**，不是只给一个分。"
3. 点 **确认线索**（或"保留/排除"）→ 提示保存成功。
4. 关掉抽屉，点 **导出明细** → 下载 CSV，说："导出带运行批次、来源行号、复核记录。"

> 如果老师问"58 个账号怎么来的"：滑窗 10 分钟 + 文本相似度 ≥ 阈值 + 同一事件内去重，算法在 `lib/core/coordination-scan.ts`。

---

## 2. 评论检测：单条打分（60 秒）

点 **评论检测**，在文本框输入：

```
兄弟们冲！统一口径刷起来，九点准时集合！！！
```

点 **开始检测**。

说：
> "这是 WB01 文本模型，8,192 维字符 n-gram 哈希 + 线性模型，**权重就在仓库里**，服务端直接推理。
> 输出的是'文本筛查分数'，不是账号定性；`confidence` 只由文本长度算出来，页面上如实标注。"

再点 **批量筛查**（里面已有示例）→ 200 条上限、空行单独报错。

---

## 3. 事件扫描：新事件在线入库（60 秒）

点 **事件扫描** → 点 **填入示例** → 点 **开始扫描并入库**。

说：
> "刚才 803 条是离线批次。这里是**新事件**：现场跑清洗、分组、排序，然后真的写库——
> 事件、线索、成员、相似边、图谱各一张表。扫描有自己的 `runId`，和离线 803 批分开，不会污染对账。"

指一下结果里的"跳过原因"和"清洗版本 online-1.0"。

> 老师若问"能不能复现 803"：诚实回答——"离线批次用的是算法组 341 项短句词典，在线只有 10 条通用短句，口径不同，所以两条批次分开存，页面上写明。"

---

## 4. 数据导出 + 操作日志（40 秒）

点 **数据导出**：指 12 个表 + 整库备份 + 建表语句。
说："任何一张表都能下 CSV/JSON，下载会写审计。"

点 **操作日志**：指刚才那几条"账号登录 / 线索复核 / 事件扫描"。
说："谁在什么时候做了什么，都能查。"

---

## 5. 模型接入：能力边界（40 秒，加分项）

点 **模型接入** → 点 **运行自检**。

说：
> "五种能力分开标状态：评论文本筛查、协同线索、在线扫描是 ready；账号 BERT 是 not_ready——算法组只给了模板没有权重，接口返回 503，**不会用 mock 分数充数**。
> 另外两条分数不合并：文本筛查分数和协同排序分，各自的口径写在页面上。"

---

## 收尾（20 秒）

> "技术上：Next.js App Router 做前端，后端是一个函数式路由文件，数据层 SQLite（本地 D1），
> 构建产物是单端口 Node 服务，一条命令起站点；验收有 93 项接口用例 + 每个按钮的点击审计。"

---

## 万一现场出问题

| 现象 | 处理 |
| --- | --- |
| 页面打不开 | 关掉终端里的旧进程，重新 `npm start`，等 "Ready on http://0.0.0.0:3000" |
| 数据空了 | 说明连到了空库：确认 `.wrangler/state` 还在；或用交接包里的内部版 zip 恢复 |
| 端口占用 | `PORT=3100 npm start`，地址相应改成 3100 |
| 某个按钮没反应 | 打开 F12 看 Network 的 `/api/v1/...` 返回码，把返回的 `error.code` 念出来即可定位 |
