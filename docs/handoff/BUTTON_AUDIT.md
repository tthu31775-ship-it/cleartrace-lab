## 4. 判定口径的说明

| 元素类型 | 为什么算"有反应" |
| --- | --- |
| 导航类（指标卡、去复核、查看接入文档） | URL hash 变化 |
| 弹层类（查看、研判、新建任务） | 出现 `.modal/.drawer` |
| 写库类（复核、创建令牌、导入） | 发出 `/api/v1` 请求且出现提示条 |
| 下载类（导出、CSV/JSON） | Playwright 的 `download` 事件 |
| 纯前端（图谱缩放、重置、区间切换） | 页面文本或 SVG 变换 |
| 按设计禁用（图谱重置在初始视图、未就绪能力） | `disabled` 为真即算通过，但要求有 tooltip 说明 |
