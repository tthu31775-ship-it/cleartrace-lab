三、已核实的迁移基础
锁定 vinext@1.0.0-beta.5 自带 Node prod-server 和 standalone。
其 build CLI 支持 --mode；不能照抄 build --config、build --standalone 或 build --platform=node。
请在 vite.config.ts 新增 mode==="node" 的分支，使用 vinext({nextConfig:{output:"standalone"}}) 并完成运行环境模块选择；该分支不加载 sites()、connectorPreview()、cloudflare()。
完成适配后，生产构建方式为：
node node_modules/vinext/dist/cli.js build --mode node
Node入口：
node dist/standalone/server.js
当前代码尚没有这个分支。standalone读取PORT和HOST，不会自动读取任意.env文件。
当前 npm start 是 wrangler dev --local，不能把它当普通服务器的生产启动。
